# Customer Churn Analytics & Risk Dashboard

A portfolio project demonstrating customer churn analysis using Python, SQL-style analysis, Excel concepts and business-focused insights.

## Highlights
- 1,000-customer telecom dataset
- Data cleaning and exploratory analysis
- Churn distribution and contract analysis
- Business recommendations for customer retention

## Tech Stack
- Python
- Pandas
- Matplotlib
- SQL (analysis workflow)
- Microsoft Excel
- Git/GitHub

## Folder Structure

```
    ├── churn_distribution.png

```

## Business Insights
- Month-to-month customers show higher churn risk.
- Short-tenure customers require targeted retention offers.
- Contract upgrades can reduce churn.
